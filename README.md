# 🌡️ ESP8266 Web Thermometer with AJAX (C++ / PlatformIO)

Бездротова міні-метеостанція на базі мікроконтролера **Wemos D1 mini (ESP8266)** та датчика вологості й температури **DHT11**. Проєкт реалізує вебсервер із динамічним оновленням показників у реальному часі за допомогою **AJAX (Fetch API)** без необхідності оновлювати сторінку у браузері.

---

## 📌 Особливості проєкту

* **Динамічний вебтермометр:** вимірювання температури та вологості повітря у реальному часі.
* **AJAX Auto-Update (Без перезавантаження):** JavaScript у браузері кожні 2 секунди опитує пристрій та оновлює лише показники на екрані, запобігаючи миготінню сторінки.
* **Легкий JSON API:** пристрій віддає дані у форматі `{"temp": 24.0, "hum": 45.0}` через окремий ендпоінт `/data`.
* **Захист від Bootloop:** використання безпечного пін-коду (`D1`) для підключення датчика, що усуває проблеми під час завантаження прошивки.

---

## 🛠️ Компоненти та розпіновка (Pinout)

### Необхідні деталі:
1. **Wemos D1 mini** (ESP8266) — 1 шт.
2. **DHT11** (або DHT22) — датчик температури та вологості — 1 шт.
3. Резистор 4.7 кОм - 10 кОм (бажано для лінії Data, якщо немає вбудованого на платі датчика).
4. Якісний USB-кабель.

### Схема підключення:

| Компонент (DHT11) | Пін на датчику | Пін Wemos D1 mini | GPIO (ESP8266) | Примітка |
| :--- | :--- | :--- | :--- | :--- |
| **DHT11** | `VCC` | **3.3V** або **5V** | 3.3V / 5V | Живлення датчика |
| | `DATA` | **D1** | GPIO5 | Безпечний пін для даних |
| | `GND` | **GND** | GND | Спільний мінус |
